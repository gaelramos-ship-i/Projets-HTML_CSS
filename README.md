# Portfolio d'intégrations HTML/CSS

Ce projet regroupe plusieurs intégrations réalisées dans le cadre d'exercices d'entraînement HTML et CSS.

## Contenu du projet

Ce dépôt contient plusieurs pages HTML indépendantes, chacune représentant une intégration différente :

- Boum Boum
- Délice Sucres
- Nomade
- Nomade Maquillage
- Olivia Daniel
- Marketing Agency

Chaque page a son propre fichier HTML et son propre fichier CSS associé.

## Technologies utilisées

- HTML5
- CSS3

## Objectif pédagogique

Ce projet permet de travailler :

- la structuration en HTML
- le style avec CSS
- le responsive

Ce dépôt est donc un support d'entraînement pour améliorer mes compétences en intégration web.
